RunAsDate-for-MacOS

The station logbook for one winter: each part of the job gets its own dated entry, ruled off in order.

1

Entry one: the situation

This project is an Apple Shortcut for macOS. It changes the Mac system date to a chosen earlier date, opens an application under that date, waits a few seconds, and then puts the system date back. It exists for testing software with expiry dates and for coaxing older applications that object to the current date.

2

Entry two: getting the shortcut

1. Download the file Run_As_Date.shortcut from the repository.

2. Double click it.

3. Add it to the Shortcuts library.

3

Entry three: setting it up

Open the shortcut in the app, not with the play button, and edit two things. The date goes in as MMDDHHmmYY: month first, minutes in small m, year last. The application is set by swapping the example path /Applications/Infuse.app for the path of whatever app you want to launch.

Margin note: the script contains a sleep 6 step, six seconds before the date reverts. If your app launches slowly, raise that number.

4

Entry four: running it

Tap the shortcut in the Shortcuts app or call it up with Siri. The shortcut can be extended with an action that asks for the date and application on every run, for people who switch apps often.

5

Entry five: the warning, ruled off

The shortcut runs with root rights and it moves the real system clock, not a pretend clock inside one app. The shortcut file itself is signed and encrypted, and its full script text is not published in readable form, so this page describes only what the README describes and claims nothing beyond it.

RunAsDate-for-MacOS: the calendar turned back for a few seconds, then put right, and the watch ends with the true date showing again.
